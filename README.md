# QWERTZ v2 - Anonymous Social Network

Yaş grubu tabanlı sosyal medya uygulaması. Kullanıcılar anonim olarak fotoğraf, video paylaşabilir ve yaş gruplarına göre sınırlandırılmış mesajlaşma yapabilirler.

## 🎯 Özellikler

✅ Yaş Doğrulaması (0-100)  
✅ Yaş Grubu Tabanlı Mesajlaşma  
✅ Fotoğraf ve Video Paylaşımı  
✅ Global Chat (Herkes görebilir)  
✅ Engelleme Sistemi (IP adresi)  
✅ Like ve Reply Sistemleri  
✅ 3 Bölümlü UI

## 👥 Yaş Grupları

- **0-9**: Feed'i sadece görüntüleyebilir
- **10-17**: Sadece 10-17 yaş grubu ile mesajlaşabilir
- **18-30**: 18-30 ve 30+ ile mesajlaşabilir
- **30+**: 30+ ve 18-30 ile mesajlaşabilir

## 🛠️ Stack

- **Frontend**: React.js + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: PostgreSQL
- **Auth**: Session-based
